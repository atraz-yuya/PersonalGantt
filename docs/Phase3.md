## 2. UI 構成

一覧には配置済みブロック、タスク、未配置作業、使用したサンプル空き枠を表示します。
ツールバーの「タスクを追加」でフォームを開き、各タスク行に完了切替・編集・削除を用意しています。

追加・編集のフォームで入力するのは以下の3項目のみです。

- タスク名
- 所要時間（分）
- 締切（日付と時刻）

開始時刻・終了時刻の入力欄はありません。無効な入力には理由を表示し、「保存」を無効にします。
編集中の値は下書きとして保持し、「キャンセル」ではタスクやスケジュールを変更しません。
削除は対象名を表示した確認ダイアログを経て実行します。

未完了のタスクは「配置済み」「一部未配置」「配置不能」に分け、未配置の分数も表示します。
完了済みタスクは一覧に残り、ブロックと未配置の警告から除外されます。

## 3. タスク操作のデータフロー

```text
追加・編集フォームの下書き
→ 共通入力検証（フォーム + ViewModel）
→ Task 配列の更新
→ Scheduler.schedule(tasks:availableSlots:)
→ SchedulingResult の置換
→ Observation によりブロック・タスク状態・未配置時間を更新
```

追加時は UUID を新規生成します。編集時は UUID と完了状態を維持し、3項目だけ更新します。
削除時は Task 配列から除き、完了切替時は `isCompleted` を更新して、同じ再計算経路を使います。
過去の ScheduledBlock の蓄積や直接編集は行いません。

## 4. Scheduler 再計算のタイミングと入力ルール

再計算は追加/編集の保存成功直後、削除確認後、完了/未完了切替直後に1回行います。
フォームの入力途中、無効な保存、キャンセルでは再計算しません。
既存の「再計算」ボタンと空き枠差し替え時の計算も維持しています。

- 名前は前後の空白/改行を除去し、空なら拒否します。
- 所要時間は `Int` に変換できる1分以上の整数。0、負、少数、文字、桁あふれを拒否します。
- 締切は DatePicker で選びます。共通検証でも有限の Date かつ `Date.distantPast...Date.distantFuture` の範囲内を要求します。
- 過去の締切は有効な日時として許可します。フォームに注意を表示し、締切前の空き枠がなければ配置不能になります。
- 削除済みタスクを古い編集フォームから保存しても再作成せず、エラーを返します。

## 7. 未実装事項

空き時間は起動時に生成するサンプルの3日分です。EventKit、Calendar、Reminders、CloudKit、
SwiftData 等の永続化、本格的な Gantt View は今回の対象外です。
再起動すると初期サンプルに戻り、操作したタスクは保存されません。

作業の部分的な完了実績、過去ブロックの保持、進行中ブロックの保護、現在時刻以降への切り詰めも未実装です。
完了切替は Task 全体の状態を変えます。表示する「未配置」は空き枠に置けなかった分であり、作業実績を引いた残りではありません。
既存 OS 設定は27.0のままです。実機・visionOS は未検証です。

## 8. 次の Phase に進む前に決める仕様

1. 活動可能時間: 平日/休日の時間帯、睡眠・休憩・利用不可枠、配置対象の日数。
2. 固定予定の範囲: 使用するカレンダー、終日予定、キャンセル/仮予定、重複、タイムゾーンの扱い。
3. 再配置する範囲: 現在時刻より前、進行中、過去の予定に置かれた未完了作業をどう扱うか。
4. 作業実績: Task 全体の完了と、途中まで作業した分数をどう分けて記録するか。
5. 同じ締切の優先順位: 現在は UUID 順。入力順や明示的な優先度を導入するか。
