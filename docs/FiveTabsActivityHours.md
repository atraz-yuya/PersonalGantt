# 5画面・日別稼働時間（2026-10-12）

## 画面構成

下部の移動先は「今日 / 日別 / タスク / 追加 / 待ち」です。iPhoneのコンパクト幅はTabView、Mac・iPadの通常幅は右画面下部の5ボタンを使用します。サイドバーに今日・日別・タスク・追加を重複表示しません。待ち、Calendar更新、再計算、設定を残します。設定は独立シートとして開き、閉じると元のタブへ戻ります。

追加画面はTask・Routineの2つの作成操作を持ち、既存エディターと保存・再計算処理を使用します。設定の「作成した作業の管理」に通常TaskとRoutineの削除操作を集約しました。Routineの編集・スキップ解除は既存の作業量・配置設定に残します。削除には確認ダイアログがあり、開始済みの時間枠と実績を保持します。

待ち画面では不足している所要時間・締切を補完します。任意日時のDatePicker、今日/明日などのクイック期限、既存ReminderSyncViewModelの保存経路を維持します。元Reminderに締切がある場合は元データを優先します。

## 稼働時間

初期値は平日・土日とも10:00〜24:00です。設定の「稼働時間・日付ごとの変更」で通常時間を編集し、日付ごとの上書きも作成・変更・解除できます。稼働しない日を指定できます。開始・終了はHH:mmで入力し、終了の24:00は翌日のローカル0:00を表します。逆転・同時刻・範囲外は保存できません。

今日画面の「今日の稼働時間」を押すと、その日だけの変更画面が開きます。「保存して再計算」で即時に配置へ反映し、画面を閉じます。通常の時間帯へ戻す操作も同じ経路で再計算します。

ActivitySettingsの通常時間とGregorianのローカル日付キーの上書きをSchedulingSettingsのoptionalフィールドに保存します。既存v4 checkpoint・バックアップは読み込めます。旧データのフィールド欠落時は新しい10:00〜24:00を使用します。バックアップ・復元・同期に時間設定も含みます。同期先はこのフィールドに対応したバージョンが必要です。

再計算時は取得済みfixedEventsとCalendar取得範囲から空き枠を再生成します。時間変更だけでGoogle取得は行いません。未取得期間へ確定配置しない従来の保護と、開始済み枠を保持するScheduleReplannerを使用します。日次上限・所要時間・Routine規則も引き続き適用します。夏時間の日も24:00は次のローカル暦日の開始を使います。

旧回帰テストの08/09:00〜23:00は、テスト専用の明示的フィクスチャとして固定しました。新しい既定値・日付上書き・無効入力・24:00・夏時間・即時再計算・保存/復元/同期はActivityHoursTestsで検証します。
